# Quy tắc làm việc

- Sau mỗi cập nhật hoàn tất, chạy build và kiểm tra phù hợp, rồi commit và push lên GitHub để cập nhật GitHub Pages.
- Chia công việc độc lập cho các workers cùng thực hiện; không để agent chính ôm toàn bộ công việc.
- Agent chính điều phối, tích hợp kết quả và kiểm tra trước khi triển khai.
- Chỉ commit các thay đổi thuộc nhiệm vụ, giữ nguyên thay đổi không liên quan.
