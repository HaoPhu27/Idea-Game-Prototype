# Factory Sort — Prototype chính

Băng chuyền ở trên, thùng hàng ở dưới. Đây là bản Factory Sort duy nhất đang được phát triển.

- `index.html`, `style.css`, `src/`: mã nguồn game.
- `assets/`: ảnh và font cục bộ, dùng cho cả dev và build offline.
- `dist/FactorySort_ABTest_Inverted.html`: bản standalone.

Từ thư mục cha `Factory Sort`, chạy `npm start` để mở dev tại http://localhost:8080/ab_test/; chạy `npm run build` để đóng gói và `npm test` để kiểm tra logic.

Tài liệu: [thiết kế và kỹ thuật](../docs/), [nâng cấp UI](../docs/ui-upgrade/README.md).
